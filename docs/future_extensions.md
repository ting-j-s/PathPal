# 未来扩展规划 (Future Extensions)

本文档仅作为后续扩展方向的备忘，**当前阶段不实现任何以下功能**。

---

## 可能的扩展方向

### 1. 用户系统
- 完整登录注册（JWT / Session）
- 用户画像管理
- 历史记录与偏好学习

### 2. 旅游日记
- 创建/编辑/删除旅游日记
- 图片上传
- 日记关联目的地和路线

### 3. 旅游社区
- 日记分享与浏览
- 评论和点赞
- 好友系统

### 4. 美食推荐
- 美食 POI 数据
- 基于位置的美食推荐
- 美食评价与排行

### 5. 城市级导航
- 从一个景区到另一个景区的外部路线
- 公共交通换乘
- 驾车导航

### 6. 真实地图集成
- 接入高德/百度地图 API
- 真实道路网络
- 实时交通数据

### 7. 智能体增强
- 基于 LLM 的行程规划助手
- 多轮对话式推荐
- 自然语言路线查询

### 8. 性能优化
- 图数据预加载与缓存
- 离线地图支持
- 大规模数据下的索引优化

---

## 架构预留

当前阶段在以下方面为扩展做了预留：

1. **模型层抽象**：models/ 目录设计为可替换数据源（JSON → 数据库）
2. **算法模块独立**：algorithms/ 不依赖 Flask，可单独测试和复用
3. **服务层编排**：services/ 作为业务编排层，扩展时只需新增 service
4. **API 版本化**：路由设计预留版本前缀
5. **前端模块化**：JS 文件按功能分拆，方便扩展
