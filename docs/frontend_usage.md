# 前端使用指南 (Frontend Usage)

## 启动方式

### 1. 启动后端

```bash
cd backend
python app.py
```

后端运行在 `http://127.0.0.1:5000`，提供 REST API。

### 2. 启动前端

```bash
cd frontend
python -m http.server 8000
```

前端运行在 `http://127.0.0.1:8000`，纯静态 HTML/CSS/JS。

> **注意**：两个终端需要同时运行。前端通过 `fetch` 调用后端 API。后端已启用 CORS，允许跨端口访问。

## 页面操作指南

### 首页 (index.html)

- 访问 `http://127.0.0.1:8000`
- 自动从 `/api/stats` 加载数据规模统计
- 展示项目简介、三个核心模块入口、算法亮点
- 明确标注"不做"的功能范围

### 旅游推荐页 (recommendation.html)

演示时建议操作步骤：

1. **热度推荐** — 点击「热度 Top-10 推荐」，查看按热度降序的目的地 Top-10
2. **评分推荐** — 点击「评分 Top-10 推荐」，查看按评分降序的目的地 Top-10
3. **兴趣推荐** — 使用默认 USER_001，点击「兴趣推荐 Top-10」，查看个性化匹配结果（含兴趣分和推荐理由）
4. **关键词搜索** — 输入"故宫"，排序选择"按评分"，点击「搜索」
5. **类别过滤** — 输入"park"，点击「类别过滤」，查看所有公园类型目的地
6. **类型过滤** — 选择"校园"，点击「列出目的地」，查看所有校园

结果表格展示名称、类型、类别、热度、评分、标签及算法/数据结构标签。

### 路线规划页 (route_planning.html)

演示时建议操作步骤：

1. 从「目的地」下拉框选择一个目的地（如"北京邮电大学"或"故宫"）
2. 观察交通提示：校园显示 walk/bike 可用，景区显示 walk/sightseeing_car 可用
3. 选择起点节点和终点节点
4. 选择策略：
   - **最短距离** — 点击「规划路线」，查看最短路径和 Leaflet 地图
   - **最短时间** — 选择 transport=walk，点击规划
   - **混合交通** — 每条边自动选择最快交通
5. 查看路段详情表：每段显示距离、交通方式、拥挤度、理想速度、真实速度、耗时
6. 尝试多目标路线：输入途经节点（逗号分隔），点击「多目标规划」

地图上不同颜色表示不同交通方式：
- 蓝色 = walk
- 绿色 = bike
- 橙色 = sightseeing_car

### 场所查询页 (nearby.html)

演示时建议操作步骤：

1. 从「目的地」下拉框选择一个目的地
2. 选择「当前所在节点」
3. 点击「查询全部附近设施」— 查看按道路距离排序的设施列表
4. 选择类别（如 toilet），点击「按类别查询」
5. 输入关键词（如"超市"），点击「关键词搜索」
6. 点击某个设施的「查看路径」按钮，在地图上查看起点到该设施的最短路径

地图上绿色标记为设施位置，红色标记为当前所在节点。点击设施标记可查看名称、类别和道路距离。

### 室内导航页 (indoor_navigation.html)

Demo 功能，操作简单：
1. 选择建筑
2. 输入起点和终点节点 ID（如 IN_B101, IN_B201）
3. 点击「查询室内路线」
4. 查看路径结果和步骤详情

## 常见问题

### 后端未启动

- 现象：页面显示"错误: Failed to fetch"或网络错误
- 解决：确认已运行 `python backend/app.py`

### CORS 错误

- 后端已全局启用 CORS，无需额外配置
- 如果使用其他端口或域名，需修改 `backend/app.py` 中的 CORS 设置

### 端口占用

```bash
# 查看 5000 端口
lsof -i :5000
# 查看 8000 端口
lsof -i :8000
# 更换前端端口
python -m http.server 8080
```

### 地图不显示

- 确认网络可访问 OpenStreetMap 瓦片服务
- 检查浏览器控制台是否有 Leaflet 加载错误
- route_planning.html 和 nearby.html 需要 Leaflet CDN

## 页面约束

所有页面均遵守以下约束：
- 不做城市级外部导航
- 不做跨景区/跨校园路线
- 路线规划只在 internal_map_id 内部进行
- 场所查询使用道路距离排序，非直线距离
- 不包含日记、美食、登录注册功能
