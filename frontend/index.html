基于数据结构的个性化旅游推荐与景区/校园内部路径规划系统 — 数据结构课程设计项目

项目简介

PathPal 是一个基于 Python Flask 的个性化旅游辅助系统，面向数据结构课程设计。 当前阶段聚焦于三个核心功能模块：旅游推荐、景区/校园内部路线规划和场所查询。

所有核心算法自行实现（排序、查找、Dijkstra、Top-K），数据以 JSON 文件存储，不使用数据库。 路线规划仅发生在景区/校园内部道路图中，不做城市级外部导航。

明确不做：旅游日记、美食推荐、完整登录注册、城市级外部导航、跨景区/跨校园路线规划

核心功能模块

旅游推荐

从 217 个目的地中按热度、评分、兴趣推荐 Top-K，支持关键词搜索与类别过滤。使用自实现 Top-K 堆、排序、查找算法。

内部路线规划

景区/校园内部道路图的最短路径规划，支持最短距离、最短时间、混合交通策略。基于自实现 Dijkstra 算法。

场所查询

查询景区/校园内部附近服务设施（洗手间、商店、食堂等），按道路网络距离排序，不使用经纬度直线距离。

核心算法

  • Top-K 堆 — 小顶堆维护大小为 K，取 Top-K 最大元素，时间复杂度 O(N log K)
  • 自定义排序 — 快速排序、归并排序、堆排序、多键稳定排序
  • 关键字查找 — 线性查找 + 哈希索引，支持中文字串匹配
  • 邻接表图 — 自定义 Graph 类，按 map_id 筛选构建
  • Dijkstra 最短路 — 4 种权函数（距离/时间/交通工具/混合）
  • 道路距离附近查询 — 对每个设施计算 Dijkstra 道路最短路径距离
  • 多交通工具混合路径 — 每条边自动选择最快交通工具（walk / bike / sightseeing_car）
