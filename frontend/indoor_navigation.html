室内导航

教学楼与景区展馆内部路径规划，支持电梯/楼梯跨层导航，SVG 楼层拓扑图展示

功能说明

  • 支持教学楼和景区展馆内部路径规划
  • 覆盖大门 → 走廊 → 电梯/楼梯 → 跨层 → 目标房间的完整导航
  • 基于自实现 Dijkstra 算法，权重 = edge.distance（米）
  • SVG 楼层拓扑图展示，路径高亮、节点颜色区分类型
  • 当前包含 2 栋多层建筑（4 层教学楼 + 3 层展馆）

算法与数据结构说明

数据结构：室内图邻接表 (Indoor Graph Adjacency List) — 节点存储楼层/类型/坐标，边存储连接与距离

节点类型：entrance（入口）、lobby（大厅）、elevator（电梯）、stairs（楼梯）、corridor（走廊）、classroom（教室）、office（办公室）、restroom（洗手间）、service_point（服务点）、exhibition_hall（展厅）、exit（出口）

边类型：corridor（走廊）、elevator（电梯）、stairs（楼梯）、doorway（门）

图结构：无向图，每条边对应两个方向的邻接关系

核心算法：Dijkstra 最短路径 — 权重 = edge.distance（米），O(V²)

路径策略：大门 → 走廊 → 电梯/楼梯 → 跨层 → 走廊 → 目标房间

当前限制：暂不接入室外路线、暂不做真实楼层平面图、暂只做最短距离策略
